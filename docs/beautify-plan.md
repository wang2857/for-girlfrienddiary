# beautify 分支：视觉打磨计划

从 `v1.0.0` 拉出。只改"看起来怎么样"，不改数据结构和核心逻辑；每项都能单独回退。
改动先在模拟器上看，满意再合回 `main`。

## 原则

1. **功能冻结**：不在这条分支加新功能，只改视觉、动效、间距、层级
2. **数据零改动**：不碰 `entry` / `tag` 表结构（真要加列，回 main 走迁移）
3. **系统字体优先**：界面文案继续用手机系统字体；只有日记正文允许换字体
4. **一条一个 commit**：方便挑着 merge（`git cherry-pick`）

## 待做

### 1. 字体与排版

- [ ] 正文默认字号/行高给一个更"耐读"的组合（现在 16sp / 26sp，可试 17sp / 30sp）
- [ ] 标题层级拉开：月份分组、周分组、日期三级的字号与字重重新排一遍
- [ ] 中文标点挤压（`TextStyle` + `lineBreak`），避免行首出现 `，。`
- [ ] 数字用 tabular figures（`FontFeatureSetting("tnum")`），时间列表对齐更整齐

### 2. 时间线

- [ ] 卡片间距从 10dp 调到 12–14dp，长列表更透气
- [ ] 日期行的元信息（农历/天气）降一档灰度，主角是日期和正文
- [ ] 粘性月份头加一层与纸面同色的渐变遮罩，滚动时不"硬切"
- [ ] 空状态插画（现在只有一句问候）

### 3. 编辑器

- [ ] 顶部日期行与正文之间加一条更细的分隔
- [ ] 工具栏图标化（图片/横线/字体/背景/删除），文字在 5 项时已经偏挤
- [ ] 图片块圆角与卡片统一（现在 16dp，卡片 24dp）
- [ ] 保存成功的「✓ 已收好」换成带缩放的轻动效

### 4. 动效

- [ ] 列表 → 编辑器的共享元素过渡（Compose `SharedTransitionLayout`，不依赖厂商 SDK）
- [ ] 日历切月加横向滑动，今天格子做一次脉冲
- [ ] 底部 tab 选中态加一条"墨迹"指示器

### 5. 深色与配色

- [ ] 8 种心情色在深色模式下的对比度复核（当前 22% 叠底）
- [ ] 动态取色（Android 12+）与"纸感米白"二选一时给个开关
- [ ] 自定义纸张的蒙版比例按图片亮度自适应，而不是固定 76% / 82%

### 6. 图标与品牌

- [ ] 应用图标重做（现在是自适应图标 + 纯色底）
- [ ] 统一一套线性图标（返回/保存/搜索/锁/收藏），替换 emoji 按钮

## 验证清单

- 浅色 / 深色各截一组 `docs/` 对照图
- 小窗 700×1000 与 1080×2520 两种尺寸检查折行
- `./build.sh :app:lintDebug` 保持 0 Error
- 合并前：`git rebase main`（或 merge main）确保不落后

## 合并方式

```bash
git checkout main
git merge --no-ff beautify
./build.sh assembleDebug && ./build.sh :app:lintDebug
```
